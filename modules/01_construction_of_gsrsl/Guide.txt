# 2. Core Algorithms & Logic

## Step 1: Preprocessing (Denoising)
Apply Savitzky-Golay filtering to the raw ground spectra to remove high-frequency noise while preserving absorption features.
*   **Library**: `scipy.signal.savgol_filter`
*   **Parameters**: `window_length=15`, `polyorder=3`.

## Step 2: Physical Resampling (SRF Convolution)
To map the continuous ground spectrum (1nm resolution) to the discrete satellite bands (approx 4-8nm resolution), use Gaussian integration.

**Logic for each satellite band `i`:**
1.  Define the Gaussian Spectral Response Function (SRF) for band `i`:
    `sigma = fwhm_i / (2 * sqrt(2 * ln(2)))`  (approx `fwhm_i / 2.355`)
    `weight(lambda) = exp( - (lambda - center_lambda_i)^2 / (2 * sigma^2) )`
    
2.  Calculate the simulated reflectance `R_sat_i`:
    `numerator = sum( R_ground(lambda) * weight(lambda) )` over the relevant wavelength range.
    `denominator = sum( weight(lambda) )`
    `R_sat_i = numerator / denominator`

*Implementation Note*: Ensure the ground wavelength range covers the satellite band range. If ground data is missing for a specific band (e.g., edges), handle gracefully (e.g., use nearest neighbor or define as 0).

## Step 3: Class Aggregation
1.  Group all resampled vectors by their `class_id`.
2.  Calculate the **Mean Spectrum** (Arithmetic Average) for each class.
    `Standard_Vector_Class_k = Mean(All_Samples_in_Class_k)`
    Shape: (297,)
